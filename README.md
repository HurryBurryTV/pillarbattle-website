# Pillarbattle hemsida

Detta är en statisk hemsida. Ladda upp hela mappen eller zip-filen till Netlify.

Viktiga filer:

- `index.html` - text, länkar, server-IP och innehåll
- `styles.css` - färger, layout och design
- `script.js` - kopiera-IP-knapp och nedräkning
- `assets/pillarbattle.png` - loggan

Snabb uppladdning:

1. Gå till https://app.netlify.com/drop
2. Dra in `pillarbattle-website.zip`
3. När sidan är uppladdad får du en tillfällig Netlify-länk
4. Koppla sedan domänen `pillarbattle.se` i Netlify under Domain settings
